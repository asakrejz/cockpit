setup_live.title = Live update (optional)
setup_live.intro_1 = By default Cockpit asks Jira and GitHub every few minutes. This works without any setup and stays that way. With webhooks, GitHub and Jira report by themselves as soon as something changes, and Cockpit syncs right away.
setup_live.intro_2 = For this, GitHub and Jira must be able to reach your Cockpit from the internet. That only works through a tunnel that you start yourself. Cockpit installs and starts none of this. If you do not need it: skip.
setup_live.intro_3 = A webhook is only a signal. Cockpit takes nothing from the message. It fetches the data as always through the signed-in connection.
setup_live.step1_title = 1. Turn on webhooks
setup_live.enable = Enable webhooks
setup_live.public_url_label = Public address of the tunnel
setup_live.public_url_hint = For display only: Cockpit builds the addresses to copy from it and never calls them itself. You get it from your tunnel (step 2). It must start with https://.
setup_live.save = Save
setup_live.fallback = As long as webhooks arrive regularly, Cockpit asks the source only every {min} minutes as a safety net. If they stop, the normal interval applies again.
setup_live.step2_title = 2. Start a tunnel (you, not Cockpit)

setup_live.tunnel_address = The tunnel shows you an address with https://. Enter it above as "Public address". Quick tunnels get a new address on every start. Then you must change it at GitHub and Jira too.
setup_live.security_label = Security:
setup_live.security = Only the two addresses /api/webhooks/github and /api/webhooks/jira are meant for the internet. Everything else in Cockpit rejects requests with a foreign host name. It is still better if your tunnel only lets paths under /api/webhooks/ through (with Cloudflare, e.g. with a rule for the path). Without a secret Cockpit accepts nothing.
setup_live.github_title = 3. GitHub webhook
setup_live.github_open = Open the settings of your repo at GitHub (Settings › Webhooks › Add webhook). If you use a GitHub App, open the page of the app instead (Settings › Developer settings › GitHub Apps › your app › General › Webhook, tick "Active").

setup_live.jira_title = 4. Jira webhook
setup_live.jira_open = In Jira (as administrator) open Settings › System › WebHooks › "Create a WebHook".
setup_live.jira_secret_before = Paste the secret into "Secret". Jira signs every message with it. If you do not have this field (older Jira versions, automation rules), append the secret to the address as
setup_live.jira_secret_after = instead. This is weaker: the secret is then part of the address and can show up in logs.
