# Setup step 2: connect Jira.
setup_jira.title = Connect Jira
setup_jira.intro = This lets Cockpit show you your tickets. You can sign in in two ways – pick one above. The API token is the easier one: a password just for programs, which you create yourself in your Atlassian account.
setup_jira.good_to_know = Good to know:
setup_jira.good_to_know_text = The access has the rights of your account. If Cockpit should only read, it is best to use an account or role without write rights. You can take the access away at any time.
setup_jira.picker_aria = Way to sign in to Jira
setup_jira.oauth_title = With the Atlassian app (OAuth)
setup_jira.oauth_intro = You create a small “app” of your own once in the Atlassian developer console. Cockpit signs you in with it without passing on a password, and you can take the access away at any time. It takes more clicks, and your company must allow own apps.
setup_jira.client_id_missing = Enter the client ID from the Atlassian console.
setup_jira.client_id_saved = Client ID saved.
setup_jira.site_saved = Site saved.
setup_jira.client_removed = Client ID and client secret are removed.
setup_jira.projects_saved = Projects saved.
setup_jira.oauth_s1 = 1. Create an app in the Atlassian developer console
setup_jira.oauth_open = Open
setup_jira.oauth_open_rest = and sign in with your Atlassian account (the one you use for Jira).
setup_jira.oauth_create = Click “Create” and choose “OAuth 2.0 integration”. Enter a name, for example “Cockpit local”, tick the box for the terms and click “Create”.
setup_jira.oauth_permissions = Choose “Permissions” on the left. If the console asks at which level the rights should apply (resource level), choose the level of the resource, not “User identity”. Next to “Jira API” click “Add” and then “Configure”.
setup_jira.oauth_scopes = Under “Classic scopes” open “Edit Scopes”, tick these three rights and save:
setup_jira.scope_read = Read tickets
setup_jira.scope_write = Comment on tickets and change their status
setup_jira.scope_user = Read names of people
setup_jira.oauth_authorization = Choose “Authorization” on the left, click “Add” (or “Configure”) next to “OAuth 2.0 (3LO)” and enter this address as “Callback URL”. Then “Save changes”:
setup_jira.callback_url = Callback URL
setup_jira.oauth_settings = Choose “Settings” on the left. There you find the “Client ID” and the “Secret”. You enter both below in a moment.
setup_jira.oauth_s2 = 2. Enter client ID and client secret
setup_jira.client_id = Client ID
setup_jira.client_id_hint = Not secret. Copy it exactly as it is shown in the console.
setup_jira.client_id_save = Save client ID
setup_jira.client_id_remove = Remove client ID
setup_jira.remove_first = To remove it, first disconnect below under “4. Sign in” (there you can also have the client ID and secret forgotten).
setup_jira.remove_confirm = Really remove? The client ID is deleted from the configuration and the client secret from the .env file. Afterwards you have to enter both again to sign in with OAuth.
setup_jira.remove_yes = Yes, remove
setup_jira.cancel = Cancel
setup_jira.secret_label = Client secret
setup_jira.secret_hint = Secret like a password. It is only saved in the file config/.env in the project folder on this computer and never shown again.
setup_jira.site_title = Choose a site (only if you have several)
setup_jira.site_label = Site
setup_jira.site_hint = Only needed if your Atlassian account gives access to several sites. Name, address or ID of the site. Leave empty: Cockpit takes the only site. Applies after the next sign-in.
setup_jira.site_save = Save site
setup_jira.projects_title = 3. Which projects? (optional)
setup_jira.projects_label = Jira projects
setup_jira.projects_hint = Keys separated by commas, e.g. BUILD, WEB. Leave empty: Cockpit then shows your tickets and the ones you watch. In the inbox you can choose a project later.
setup_jira.projects_save = Save projects
setup_jira.sign_in_title = 4. Sign in
setup_jira.sign_in_text = A page from Atlassian opens. Check the name of your site there and confirm with “Accept”.
setup_jira.site_missing = First enter the address of your Jira site.
setup_jira.email_missing = Enter the email address of your Atlassian account.
setup_jira.address_saved = Address and email saved.
setup_jira.token_s1 = 1. Address of your Jira site
setup_jira.address_label = Jira address
setup_jira.address_hint = This is how the address starts when you open Jira in the browser. You can also simply paste it – with https:// and everything after it.
setup_jira.address_placeholder = company.atlassian.net
setup_jira.uses = Cockpit uses:
setup_jira.token_s2 = 2. Email address of your Atlassian account
setup_jira.email_label = Email address
setup_jira.email_hint = The address you use to sign in to Atlassian.
setup_jira.token_s3 = 3. Create a token
setup_jira.token_step1 = Click “Open token page” and sign in to Atlassian. The page opens in a new tab.
setup_jira.token_page = Open token page
setup_jira.token_step2 = Click “Create API token”.
setup_jira.token_step3 = Enter a name, for example “Cockpit”, and choose an expiry date. A shorter one is safer; when it expires, you simply create a new one.
setup_jira.token_step4 = Click “Create” and then “Copy”. The token is only shown now. Paste it right below.
setup_jira.token_label = Token
setup_jira.token_hint = Secret like a password. It is only saved in the file config/.env in the project folder on this computer and never shown again.
setup_jira.check_title = 4. Check the connection
setup_jira.check_text = Cockpit saves the address and email and asks Jira who you are. It only reads, nothing is changed.
setup_jira.check_button = Check connection
setup_jira.connected = Connected – with API token
setup_jira.not_checked = Not checked yet
setup_jira.projects_failed = The projects could not be loaded: {error}
setup_jira.all_projects = All projects
setup_jira.choice_saved = Choice saved.
setup_jira.choice_title = Which projects should Cockpit show?
setup_jira.choice_text = Choose a project or “All projects”. You can change this later in the inbox.
setup_jira.loading = Loading your projects …
setup_jira.no_projects = Jira shows no projects for this account. You can leave “All projects”.
