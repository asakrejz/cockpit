setup_container.intro_title = Container-Programm
setup_container.intro_1 = Cockpit lässt seinen Agenten später in einem „Container“ arbeiten. Das ist ein abgeschlossener Arbeitsraum auf deinem Rechner. So kann der Agent Code ausprobieren, ohne etwas an deinen Dateien zu verändern.
setup_container.intro_2 = Dafür brauchst du ein kostenloses Programm, das solche Container startet. Du brauchst es erst, wenn der Agent wirklich arbeitet. Du kannst diesen Schritt also auch überspringen.
