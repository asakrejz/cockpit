setup_live.title = Live-Update (optional)
setup_live.intro_1 = Normalerweise fragt Cockpit Jira und GitHub alle paar Minuten ab. Das funktioniert ohne jede Einrichtung und bleibt so. Mit Webhooks melden sich GitHub und Jira von selbst, sobald sich etwas ändert. Cockpit gleicht dann sofort ab.
setup_live.intro_2 = Dafür müssen GitHub und Jira dein Cockpit aus dem Internet erreichen können. Das geht nur über einen Tunnel, den du selbst startest. Cockpit installiert und startet nichts davon. Wenn du das nicht brauchst: überspringen.
setup_live.intro_3 = Ein Webhook ist nur ein Signal. Cockpit übernimmt nichts aus der Nachricht. Es holt die Daten wie immer über die angemeldete Verbindung.

setup_live.public_url_hint = Nur zur Anzeige: Cockpit baut daraus die Adressen zum Kopieren und ruft sie nie selbst auf. Du bekommst sie von deinem Tunnel (Schritt 2). Sie muss mit https:// beginnen.
setup_live.save = Speichern
setup_live.fallback = Solange Webhooks regelmäßig ankommen, fragt Cockpit die Quelle nur noch alle {min} Minuten zur Sicherheit ab. Bleiben sie aus, gilt wieder das normale Intervall.

setup_live.security_label = Sicherheit:
setup_live.security = Nur die zwei Adressen /api/webhooks/github und /api/webhooks/jira sind für das Internet gedacht. Alles andere in Cockpit lehnt Anfragen mit fremdem Adressnamen ab. Besser ist trotzdem, wenn dein Tunnel nur Pfade unter /api/webhooks/ durchlässt (bei Cloudflare z. B. über eine Regel für den Pfad). Ohne Secret nimmt Cockpit nichts an.
